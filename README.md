# ASSIGNMENT-06
# OOP Practice Assignments (Traditional OOP in Python)

This repository contains 21 practice assignments focused on traditional Object-Oriented Programming (OOP) concepts in Python. Each assignment is in its own folder, with a separate `app.py` file containing working code and comments for understanding.

---
## 🧠 Assignment Summary

1. **Using `self`**: Initialize student attributes using `self` and display them.
2. **Using `cls`**: Track number of objects using a class method and class variable.
3. **Public Variables and Methods**: Access a public variable and method outside the class.
4. **Class Variables and Class Methods**: Demonstrate how class variables are shared.
5. **Static Methods**: Create a utility class method that doesn’t rely on class or instance.
6. **Constructors and Destructors**: Print a message when object is created and destroyed.
7. **Access Modifiers**: Demonstrate public, protected, and private variables.
8. **Using `super()`**: Call parent constructor from child class.
9. **Abstract Classes**: Use `abc` module to define and implement abstract method.
10. **Instance Methods**: Method using instance variables of a class.
11. **Class Methods**: Track how many books added using class method.
12. **Static Methods**: Temperature conversion utility with no class context.
13. **Composition**: Include an Engine class inside a Car class.
14. **Aggregation**: Connect Department and Employee while keeping them independent.
15. **MRO & Diamond Inheritance**: Demonstrate method resolution in multiple inheritance.
16. **Function Decorators**: Decorator to log function calls.
17. **Class Decorators**: Decorator that adds a method to a class.
18. **Property Decorators**: Use @property, @setter, and @deleter.
19. **__call__ and callable()**: Make a class instance callable like a function.
20. **Custom Exception**: Define and handle a custom exception.
21. **Custom Iterable**: Build an iterable countdown class using `__iter__()` and `__next__()`.
